How I work

Four habits that show up in every project, whether the deliverable is a national payment migration or a weekend AI prototype.

01

Constraints first, architecture second

Regulatory framework, budget, timeline — understood before a single system diagram gets drawn. SAMA, CITC and NDPL compliance isn't a phase at the end, it's a design input from day one.

02

Build lean, then scale on purpose

A structurally lean team with AI-augmented workflows ships faster than a large one waiting on process. Headcount grows only where it compounds — the way it did from 15 to 130+ at BNP Paribas.

03

Migrate like downtime isn't an option

Risk isolation protocols, rollback plans, and a business-continuity mindset — because when the system is a national payment rail, "mostly working" isn't a result.

04

Lead the team and still write the code

Direction from a distance only goes so far. Staying hands-on with the same AI-augmented toolchain the team uses keeps the architecture honest and the roadmap realistic.
